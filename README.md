# Student Record Management System

## 1. Project Title
**Student Record Management System using C++ and Object-Oriented Programming**

## 2. Introduction
The Student Record Management System is a console-based application developed using C++. The main purpose of this project is to maintain and manage student academic records in an easy and efficient way.

The system allows users to add, view, search, update, and delete student records. It also performs basic academic calculations such as total marks, average marks, highest marks, and lowest marks.

This project demonstrates the practical implementation of Object-Oriented Programming concepts in C++.

## 3. Problem Statement
Managing student records manually can be time-consuming and may lead to errors. Maintaining student details and marks in registers makes searching, updating, and analyzing records difficult.

To overcome these problems, we developed a Student Record Management System that simplifies student information management through a menu-driven application.

## 4. Objectives
- To develop a simple student record management application.
- To store and manage student details efficiently.
- To reduce manual work in maintaining student records.
- To perform basic marks calculations automatically.
- To implement Object-Oriented Programming concepts.
- To improve programming and problem-solving skills.

## 5. Technologies Used
- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming
- **IDE:** Dev-C++
- **Application Type:** Console-Based Application

## 6. Functional Modules

### Module 1: Add Student Records
Allows users to enter student details such as roll number, name, and subject marks.

### Module 2: Display Student Records
Displays the details of all students stored in the system.

### Module 3: Search Student Records
Allows users to find a particular student using their roll number.

### Module 4: Update Student Records
Allows users to modify existing student information and marks.

### Module 5: Delete Student Records
Allows users to remove student records from the system.

### Module 6: Marks Analysis
Calculates the total marks and average marks of students.

### Module 7: Performance Analysis
Identifies the highest and lowest marks and calculates the class average.

## 7. Student Information
The system maintains the following details:

- Roll Number
- Student Name
- C++ Marks
- DBMS Marks
- ADSA Marks
- Mathematics Marks
- Artificial Intelligence Marks

**Marks Range:** 0–100 for each subject.

## 8. Key Features

## 9. Object-Oriented Programming Concepts Used

### Classes and Objects
Classes are used to organize student-related data and functions. Objects represent individual student records.

### Encapsulation
Data and related functions are organized within classes.

### Abstraction
The application provides simple menu options to perform operations without exposing unnecessary implementation details.

### Functions
Separate functions are used to perform different operations such as adding, displaying, searching, updating, and deleting records.

## 10. Working Procedure
1. Start the application.
2. Display the main menu.
3. Select the required operation.
4. Enter student information when required.
5. Perform the selected operation.
6. Display the result.
7. Return to the main menu.
8. Exit the application when finished.
